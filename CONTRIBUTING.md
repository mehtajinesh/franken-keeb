# Contributing

All keyboard changes follow [`docs/workflow.md`](docs/workflow.md).

- Branch from `dev`; do not commit directly to `dev` or `main`.
- Keep each branch limited to one independently testable change.
- Compile and physically test before the first push.
- Open feature pull requests into `dev`.
- Promote `dev` to `main` only after integrated hardware testing.
- Do not commit generated `.hex`, `.bin`, or `.uf2` firmware.
